# Throb7 Academic Homepage

Static GitHub Pages homepage for `Throb7`.

## Structure

- `index.html` - home page
- `publications.html` - publication list
- `awards.html` - awards and honors
- `education.html` - education background
- `styles.css` - AcademicPages-like layout and typography
- `assets/avatar-placeholder.svg` - replaceable profile image

## Deploy

For a user site, create a repository named `Throb7777.github.io`, copy these files to the repository root, then enable GitHub Pages from the `main` branch.
